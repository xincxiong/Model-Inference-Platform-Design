## 1. 产品概述

### 1.1 产品定位

厂商中立的一站式模型推理云平台，为企业和开发者提供从模型探索、推理部署、数据管理、微调训练到生产运维的全链路闭环能力。

### 1.2 核心价值主张

| 价值 | 说明 |
|------|------|
| **开箱即用** | 零运维即可调用主流开源模型，按 Token 弹性计费 |
| **灵活部署** | 从 Serverless 共享推理到独占 GPU 专属端点 |
| **全链路闭环** | 推理 → Data Lab → 微调 → 部署，消除跨工具数据搬运 |
| **AI 原生数据底座** | Lance/LanceDB 实现向量 + 多模态高性能存储与查询 |
| **厂商中立** | 不绑定模型厂商，支持 7+ 厂商 30+ 模型 |
| **企业就绪** | RBAC、SSO、零数据留存、SOC 2/GDPR 合规 |
| **国产化适配** | HAMi 统一抽象，支持 NVIDIA/昇腾/海光/寒武纪 |

### 3.3 专属端点（P0）

#### 3.3.1 核心功能

- **三步创建向导**：选择模型 → 配置 GPU → 端点配置
- **GPU 类型**：H100/A100/L40S/RTX4090/昇腾 910B
- **弹性伸缩**：min/max replicas，支持缩至零
- **自动伸缩策略**：队列深度 + 推理延迟 + GPU 利用率复合指标
- **冷启动优化**：模型预缓存、Warm Pool、预测性扩容
- **高可用**：跨 AZ 分散、故障自愈、资源溢出调度

#### 3.3.2 计费规则

- 按 GPU·时计费：GPU 单价 × GPU 数量 × 运行副本数
- min_replicas = 0 时，无流量自动缩至零，停止计费
- Warm Pool 预热副本按 50% 费率计费

### 3.4 模型微调（P0）

#### 3.4.1 训练方式

| 方式 | 说明 | 适用场景 |
|------|------|---------|
| Full Fine-tuning | 全参数训练 | 大量高质量数据 |
| LoRA | 低秩适配器 | 数据量少、快速迭代 |
| QLoRA | 量化感知 LoRA | 显存受限、超大模型 |

#### 3.4.2 RL 后训练算法

| 算法 | 适用场景 |
|------|---------|
| GRPO | 数学/推理类任务 |
| PPO | 通用 RLHF |
| DPO | 偏好数据对齐 |
| GSPO/DAPO/VAPO | 长序列/代码/价值对齐 |

#### 3.4.3 调度集成

- Volcano Gang Scheduling + Queue 隔离 + 优先级抢占
- HAMi GPU 虚拟化（内存硬隔离 + 算力配额）
- 多集群 AI 负载感知调度

### 3.5 数据实验室（P1）

#### 3.5.1 核心功能

- **推理日志浏览**：按模型/时间/项目/API Key 过滤
- **SQL 查询**：对推理日志进行查询和聚合
- **数据集预览**：在线查看内容，支持分页和采样
- **导出**：CSV / JSONL / Lance 格式
- **零数据留存**：企业客户可开启 ZDR 模式
- **向量混合查询**：向量搜索 + 全文搜索 + SQL 分析

### 3.6 可观测性（P1）

#### 3.6.1 指标体系

| 类别 | 指标 |
|------|------|
| 流量 | RPM、Input/Output TPM、Token 分布 |
| 延迟 | E2E Latency、TTFT、TPS（P50/P90/P99） |
| 伸缩 | Active Replicas、GPU Utilization、GPU Memory |
| 错误 | Error Rate by Status Code、429 Rate Limit Hits |

#### 3.6.2 外部集成

- Prometheus metrics 端点导出
- Grafana 预配置仪表盘
- Webhook 自定义告警

### 3.7 计费系统（P0）

#### 3.7.1 计费模式

| 服务 | 计费方式 | 说明 |
|------|---------|------|
| 共享推理 | Token 计价 | 输入/输出 Token 分别定价 |
| 专属端点 | GPU·时 | 副本数 × GPU 数量 × 运行时间 |
| 批量推理 | Token 计价 (50% 折扣) | 利用空闲算力 |
| 微调训练 | GPU·时 + 训练 Token | 训练使用的 GPU 时间 |

#### 3.7.2 支付方式

- 支付宝、微信支付（实时到账，支持自动代扣）
- 余额充值（手动预充值）
- 银行转账（企业客户，按月结算）
- Promo Code（营销活动/试用）
- 新用户试用：注册赠送 $1，有效期 30 天

## 4. 非功能需求

### 4.1 性能要求

| 指标 | 目标值 | 说明 |
|------|--------|------|
| TTFT | < 200ms (Fast) / < 500ms (Base) | 7B 模型基准 |
| TPS | > 80 tokens/s (Fast) / > 50 tokens/s (Base) | 7B 模型基准 |
| API Gateway 延迟 | < 10ms (P99) | 不含推理时间 |
| 并发请求数 | > 10,000 RPM | 平台整体 |

### 4.2 可用性要求

| 指标 | 目标值 |
|------|--------|
| 整体可用性 SLA | 99.9% (标准) / 99.95% (企业) |
| 故障恢复时间 (RTO) | < 15 分钟 |
| 数据恢复点 (RPO) | < 1 小时（元数据） |

### 4.3 安全要求

- TLS 1.3 全链路加密
- S3 SSE-KMS 静态加密
- 项目级数据严格隔离
- 零数据留存 (ZDR) 模式
- SOC 2 Type II / GDPR / HIPAA 合规

## 5. 用户旅程

### 5.1 新用户 Onboarding

```
注册账号 → 获得 $1 试用额度 → 浏览模型列表 → Playground 试玩
  → 创建 API Key → 调用推理 API → 查看用量统计
```

### 5.2 专属端点部署

```
选择模型 → 配置 GPU（类型/数量/区域） → 设置副本数
  → 获得 routing_key → 通过 API 调用 → 监控性能指标
```

### 5.3 微调训练流程

```
上传数据集 → 创建微调任务（选择算法/参数） → 等待训练完成
  → 查看评测指标 → 部署为推理端点 → 对比微调前后效果
```
